📊 Análise de Vendas — Projeto Python

Projeto simples de análise de dados de vendas desenvolvido em Python utilizando Pandas e Matplotlib.

🎯 Objetivo

Analisar as vendas de uma pequena loja e obter informações como:

Faturamento total;
Quantidade de produtos vendidos;
Faturamento por produto;
Produto com maior número de vendas;
Visualização dos dados através de gráficos.
🛠️ Tecnologias utilizadas
Python
Pandas
Matplotlib
📁 Estrutura
projeto-vendas/
├── projeto_vendas.py
└── README.md

📊 Dataset

O projeto utiliza um pequeno conjunto de dados criado manualmente contendo:

Dia da venda;
Produto;
Quantidade vendida;
Preço do produto;
Faturamento.
📈 Resultados

Através da análise, é possível identificar quais produtos possuem maior volume de vendas e quais geram maior faturamento.

Também foi criado um gráfico de barras para facilitar a visualização dos resultados.

🚀 Como executar

Instale as bibliotecas necessárias:

pip install pandas matplotlib


Depois execute:

python projeto_vendas.py

📚 Aprendizados

Este projeto foi desenvolvido para praticar conceitos básicos de Análise de Dados com Python, principalmente:

Criação e manipulação de DataFrames;
Agrupamento de dados com groupby();
Operações matemáticas em colunas;
Cálculo de métricas;
Criação de gráficos;
Interpretação de dados.
